# Assignment 5 – React Custom Hooks

This project is created as part of Assignment 5 for the MERN Stack course.
The main objective of this assignment is to understand and implement custom hooks in React.

## Description
In this project, a custom hook named `useFetch` is created to fetch data from an external API.
The hook handles loading and error states and returns the fetched data.
The fetched data is then displayed in a React component.

## Features
- Custom React Hook (`useFetch`)
- Uses useState and useEffect
- Fetches data from an API
- Displays loading and error messages
- Simple and clean UI

## API Used
https://jsonplaceholder.typicode.com/photos
